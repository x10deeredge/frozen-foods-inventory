App Store Privacy & Data Sovereignty

100% Local Data Ownership: All store records, transactions, inventory levels, supplier contacts, and client names are maintained strictly within your private database instance. No data is harvested, analyzed, or shared with any third party.

Zero Third-Party Telemetry: PANDA ERP does not include any third-party advertising SDKs, analytics tracking beacons, or telemetry scripts.

Cryptographic Security: User credentials are protected using salted one-way hashing algorithms. Session security complies with standard commercial application guidelines.

Data Portability: You can export full user JSON backups or printable audit statements anytime with a single click.
